# AmountText

The amount as it appears in an email or a WhatsApp message, written the way the visitor's
interface language writes numbers: `US$ 45,100.25` in English, `US$ 45.100,25` in German,
`US$ 45 100,25` in French. The currency is always US dollars, so the symbol is fixed rather
than taken from the culture (which would say euro for German).
