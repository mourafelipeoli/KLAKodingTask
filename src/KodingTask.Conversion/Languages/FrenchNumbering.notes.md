# FrenchNumbering

How a French-speaking region names 70, 80 and 90. Everything else is shared.

| | 70 | 80 | 90 | Used in this app by |
|---|---|---|---|---|
| `Standard` | soixante-dix | quatre-vingts | quatre-vingt-dix | fr-FR, fr-CA |
| `Belgian` | septante | quatre-vingts | nonante | fr-BE |
| `Swiss` | septante | huitante | nonante | fr-CH |

Canada counts like France, so `fr-CA` uses `Standard`.

Switzerland is not uniform: Vaud, Valais and Fribourg say *huitante*, while Geneva and
Neuchâtel mostly say *quatre-vingts*. `Swiss` follows the cantons that use the distinct
Swiss form, which is what makes the variant worth offering.
