# PolishSpeller (pl-PL)

| Amount | Output |
|---|---|
| 1 | jeden dolar |
| 2 | dwa dolary |
| 5 | pięć dolarów |
| 22 | dwadzieścia dwa dolary |
| 25,1 | dwadzieścia pięć dolarów i dziesięć centów |
| 0,01 | zero dolarów i jeden cent |
| 45 100 | czterdzieści pięć tysięcy sto dolarów |
| 999 999 999,99 | dziewięćset dziewięćdziesiąt dziewięć milionów dziewięćset dziewięćdziesiąt dziewięć tysięcy dziewięćset dziewięćdziesiąt dziewięć dolarów i dziewięćdziesiąt dziewięć centów |

## Rules

- **Three noun forms after a number**: exactly one takes the singular ("jeden dolar");
  a number ending in 2, 3 or 4, except 12, 13 and 14, takes the nominative plural ("dwa
  dolary", "dwadzieścia dwa dolary"); everything else takes the genitive plural ("pięć
  dolarów", "dwanaście dolarów", "dwadzieścia jeden dolarów", "zero dolarów"). The same rule
  picks "tysiąc / tysiące / tysięcy" and "milion / miliony / milionów" for each group, and
  "cent / centy / centów".
- **A lone one is silent before "tysiąc" and "milion"**: "tysiąc dolarów", "milion dolarów",
  but "sto jeden tysięcy".
- **Each order of magnitude is its own word**: "dwieście", "trzysta", "pięćset";
  "dwadzieścia", "pięćdziesiąt"; tens and units are separate words ("czterdzieści pięć").
- **Masculine forms**: "dolar", "cent", "tysiąc" and "milion" are masculine, so two is
  "dwa", never "dwie".
- **"i" between dollars and cents**: "dwadzieścia pięć dolarów i dziesięć centów".
